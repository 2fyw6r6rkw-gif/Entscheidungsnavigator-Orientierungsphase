# Zwei Lernnavigatoren zum Mittel- und Medieneinsatz

## Enthaltene Dateien
- `index.html`: gemeinsame Startseite (GitHub Pages-Einstieg)
- `orientierung.html`: klickbarer Entscheidungsbaum (Variante 1)
- `vertiefung.html`: sechsstufiger Reflexionsnavigator (Variante 2)
- `.nojekyll`: verhindert eine zusätzliche Jekyll-Verarbeitung auf GitHub Pages

Die beiden Tools sind unabhängig voneinander verwendbar. Alle CSS- und JavaScript-Bestandteile befinden sich in den jeweiligen HTML-Dateien. Es werden keine externen Bibliotheken geladen; keine Benutzer-Eingaben werden an einen Server übertragen.

## Lokal verwenden
`index.html` doppelklicken. Im Browser die Variante auswählen. Beide Navigatoren funktionieren auch direkt durch Öffnen ihrer HTML-Datei.

## GitHub Pages veröffentlichen
1. Auf GitHub ein neues **öffentliches Repository** erstellen, z. B. `medieneinsatz-navigator`.
2. Alle vier Dateien aus dem entpackten ZIP **in das Hauptverzeichnis** (Root) des Repositorys hochladen – nicht in einen zusätzlichen Unterordner.
3. Repository → **Settings** → **Pages** → unter **Build and deployment** „Deploy from a branch“ wählen.
4. Als Branch `main` und Ordner `/ (root)` auswählen und speichern.
5. Die von GitHub angezeigte GitHub-Pages-URL öffnen. Sie führt zur `index.html`; die beiden Varianten sind dort verlinkt.

Alternativ kann bei GitHub Pages auch der Ordner `docs/` verwendet werden, sofern die Dateien darin liegen und dieser Ordner in den Einstellungen ausgewählt ist.

## Didaktische und fachliche Grenzen
- Die ICF-Auswahl in Variante 1 enthält exemplarische Kategorien mentaler Funktionen und **keine vollständige ICF-Datenbank**. Sonstige Körperfunktionen sind als Freitext möglich. Verifikation: amtliche ICF-Referenz des BfArM.
- Personenbezogene Faktoren sind nicht als ICF-Codes klassifiziert.
- Die Feedback-Logik in Variante 2 erkennt **fehlende Erläuterungen**, validiert aber **nicht** deren fachliche Qualität oder Wirksamkeit.
- PDF über die Druckfunktion des Browsers („Als PDF speichern“). Variante 2 ermöglicht zusätzlich TXT-Export.
- Keine realen Personen- und Gesundheitsdaten eintragen, sofern kein datenschutzrechtlich geeignetes Einsatzszenario geschaffen wurde.
- Die Inhalte sind ein didaktischer Prototyp, keine diagnostische oder therapeutische Empfehlung.
